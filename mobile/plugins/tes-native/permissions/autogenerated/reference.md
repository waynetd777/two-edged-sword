## Default Permission

Everything the phone app uses

#### This default permission set includes the following:

- `allow-allow-rotation`
- `allow-speak`
- `allow-speech-pause`
- `allow-speech-resume`
- `allow-speech-stop`
- `allow-voices`
- `allow-register-listener`
- `allow-remove-listener`
